# Architecture Diagrams

This folder contains architecture diagrams at multiple view levels:

- `01_context_level.md`: high-level actors and systems.
- `02_container_level.md`: notebooks, dataset folders, and generated artifacts.
- `03_component_level.md`: internal notebook components.
- `04_data_flow_and_runtime.md`: runtime sequence and data movement.

The diagrams use Mermaid syntax. They render in many Markdown tools, including GitHub and recent VS Code Markdown preview extensions.
